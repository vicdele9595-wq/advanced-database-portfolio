**Case study:** University Student Result Portal

## Overview
A web-based academic records system for managing student course registrations, grades, and transcripts. Designed using PostgreSQL for relational data and MongoDB for complex hierarchical transcript views.

## Environment
- PostgreSQL 15+
- MongoDB 6.0+
- Git
